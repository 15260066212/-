GEO系统本地部署操作指南

芯图引擎：GEO | 生成式引擎搜索优化系统 | 版本 1.0

1. 系统架构概览

GEO系统由三个独立服务组成，需在本地开发机上同时运行：

服务端口启动命令功能
后端服务器 3000 npx tsx watch src/index.ts API服务、任务调度、RPA引擎、AI内容生成
前端界面 5174 npx vite 品牌配置、文章管理、发布控制台
Harvester采集器 3003 node server.js 浏览器Cookie采集、凭据管理、同步
前置要求：Node.js v22+、npm（非pnpm）、Playwright Chromium浏览器（npx playwright install chromium）

2. 系统启动流程

1

安装依赖

cd geo-assistant-clean
npm install
cd harvester
npm install
2

构建所有包

# 在项目根目录执行
cd packages/shared && npx tsc
cd ../content-generator && npx tsc
cd ../content-reviewer && npx tsc
cd ../publisher && npx tsc

# 同步到node_modules
Copy-Item packages\shared\dist node_modules\@zemingengine\shared\dist -Recurse -Force
Copy-Item packages\content-generator\dist node_modules\@zemingengine\content-generator\dist -Recurse -Force
Copy-Item packages\content-reviewer\dist node_modules\@zemingengine\content-reviewer\dist -Recurse -Force
Copy-Item packages\publisher\dist node_modules\@zemingengine\publisher\dist -Recurse -Force
3

启动后端服务器

cd apps\server
npx tsx watch src\index.ts

看到 芯图引擎：GEO server running at http://localhost:3000 表示启动成功。

4

启动前端界面（新终端）

cd apps\frontend
npx vite

访问 http://localhost:5174 进入管理界面。

5

启动Harvester采集器（新终端）

cd harvester
node server.js

看到 Harvester server running on port 3003 表示启动成功。

3. 平台Cookie采集流程

自动化发布需要各平台的登录Cookie。通过Harvester采集器在可视化浏览器中完成登录，自动提取Cookie。

1

启动浏览器会话

# 以知乎为例
curl -X POST http://localhost:3003/api/session/start \
  -H "Content-Type: application/json" \
  -d '{"platform": "zhihu"}'

Harvester会打开Chromium浏览器并跳转到平台登录页。

2

在浏览器中完成登录

在弹出的浏览器窗口中，手动完成登录操作：

  • 输入手机号/邮箱和密码
  • 完成验证码、滑块等安全验证
  • 登录成功后页面会跳转到平台首页
3

采集Cookie

# 用返回的sessionId查询状态
curl http://localhost:3003/api/session/{sessionId}/cookies

当 loggedIn: true 时表示检测到认证Cookie，可以采集。

4

同步Cookie到主服务器

curl -X POST http://localhost:3003/api/credentials/sync

采集的Cookie会自动保存到Harvester，调用sync接口推送到主服务器。

5

关闭浏览器会话

curl -X POST http://localhost:3003/api/session/{sessionId}/close

4. 自动化发布流程

4.1 通过前端界面发布

  1. 访问 http://localhost:5174
  2. 进入"文章管理"页面
  3. 选择要发布的文章
  4. 点击"发布"按钮，选择目标平台和发布方式（RPA）
  5. 系统自动创建发布任务并排队

4.2 通过API发布

# 创建发布任务
curl -X POST http://localhost:3000/api/publish \
  -H "Content-Type: application/json" \
  -d '{
    "articleId": "art_xxx",
    "platform": "csdn",
    "method": "rpa"
  }'

# 查询发布状态
curl http://localhost:3000/api/publish?articleId=art_xxx

4.3 任务调度

调度器每30秒轮询一次待处理任务，自动执行发布操作。失败任务会自动重试（最多2次）。

  • pending — 等待调度器处理
  • publishing — 正在执行RPA发布
  • published — 发布成功
  • failed — 发布失败（已耗尽重试次数）

5. 已知问题与解决方案

5.1 CSDN编辑器在iframe中 已修复

CSDN的博客编辑器页面使用iframe渲染内容区域，主页面没有contenteditable元素。RPA Handler已添加iframe检测和内容填充逻辑。

# 诊断日志会输出编辑器结构信息
[CSDN RPA] Editor diagnostics: { editables: [], iframeCount: 2, ... }

5.2 知乎认证机制变更 已适配

知乎已废弃 z_c0 认证Cookie，改用 q_c1 和 unlock_ticket。RPA Handler已更新认证检测逻辑，接受三种Cookie中的任意一种。

5.3 VM网络限制 环境限制

重要：当前VM环境存在网络限制，无法访问部分外部平台（如 zhuanlan.zhihu.net）。 自动化发布功能必须在能正常访问外网的本地开发机上运行。

5.4 TypeScript构建问题

  • DOM类型缺失：publisher包的tsconfig需包含 "lib": ["ES2022", "DOM"]
  • paths冲突：tsconfig.base.json中不要配置paths映射，依赖node_modules中的构建产物
  • 包同步：修改packages/*后需手动同步dist到node_modules/@zemingengine/*

5.5 端口冲突

# 查看并清理端口占用
Get-NetTCPConnection -LocalPort 3000 | Select OwningProcess | ForEach-Object { Stop-Process -Id $_ -Force }

5.6 Playwright浏览器未安装

npx playwright install chromium

6. 快速启动脚本

将以下内容保存为 start-all.ps1，一键启动所有服务：

# start-all.ps1 - GEO系统一键启动
$root = "c:\Users\Administrator\Desktop\trae work GEO\geo-assistant-clean"

# 清理端口
3000,5174,3003 | ForEach-Object {
  Get-NetTCPConnection -LocalPort $_ -EA SilentlyContinue |
    Select -Expand OwningProcess |
    ForEach-Object { Stop-Process -Id $_ -Force -EA SilentlyContinue }
}

# 启动后端
Start-Process powershell -ArgumentList "-NoExit", "-Command", "cd '$root\apps\server'; npx tsx watch src/index.ts"

# 启动前端
Start-Process powershell -ArgumentList "-NoExit", "-Command", "cd '$root\apps\frontend'; npx vite"

# 启动Harvester
Start-Process powershell -ArgumentList "-NoExit", "-Command", "cd '$root\harvester'; node server.js"

Write-Host "所有服务已启动！"
Write-Host "后端: http://localhost:3000"
Write-Host "前端: http://localhost:5174"
Write-Host "Harvester: http://localhost:3003"
